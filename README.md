## 📝 Cómo uso este repo

1. Termino un ejercicio o proyecto con mi mentor (Claude).
2. Guardo el código en la carpeta del módulo correspondiente (`ejercicios/` o `proyecto/`).
3. Actualizo `notas.md` de ese módulo con conceptos clave y dudas.
4. Hago commit describiendo qué practiqué.
5. Actualizo la tabla de progreso de este README.

### Convención de commits

```
modulo-X: descripcion corta de lo practicado

Ejemplos:
modulo-1: ejercicios de tipos de datos y conversion
modulo-2: mini examen condicionales aprobado
modulo-3: proyecto - validador de numeros con while
```
